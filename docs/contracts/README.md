# Contract Surface

This directory defines the Phase 50 contract surface for BarqFlow.

The goal is to stabilize the payloads that connect:

- backend persistence and execution
- REST responses
- frontend workflow editing
- credential selection and runtime binding
- future execution streaming

Current contract documents:

- `workflow-document.md`
- `node-schema.md`
- `execution-events.md`
- `credential-binding.md`

These documents describe the intended wire format for BarqFlow during the current parity track. They are the reference for backend DTOs, frontend TypeScript types, and contract tests.
